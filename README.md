# Desenvolvimento Web I

Repositório destinado aos exercícios práticos desenvolvidos na disciplina de **Desenvolvimento Web I**, no IFSP.

## Organização

As atividades são separadas por tecnologia e, dentro de cada tecnologia, por aula e praticando.

```text
desenvolvimento-web-1/
├── HTML/
│   └── AulaXX-MM-DD/
│       ├── Praticando-01/
│       └── Praticando-02/
├── CSS/
│   └── AulaXX-MM-DD/
│       ├── Praticando-01/
│       └── Praticando-02/
├── JavaScript/
│   └── Aula14-10-30/
│       ├── Praticando-01/
│       └── Praticando-02/
└── README.md
```

## Padrão de organização

- **Tecnologia:** HTML, CSS ou JavaScript.
- **Aula:** `AulaXX-MM-DD`, usando o número da aula e a data no formato mês-dia.
- **Praticando:** cada atividade fica em sua própria pasta, identificada em sequência (`Praticando-01`, `Praticando-02` etc.).

Os arquivos de cada atividade ficam dentro da respectiva pasta `Praticando`.
